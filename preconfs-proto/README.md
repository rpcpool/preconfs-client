# triton-preconfs-proto

`preconfs.proto` and the generated messages and gRPC clients for the Triton
Preconfs streams. Most programs want
[`triton-preconfs-client`](https://crates.io/crates/triton-preconfs-client),
which builds on this crate.

Usage and the stream contract: [rpcpool/preconfs-client](https://github.com/rpcpool/preconfs-client)
and [docs.triton.one](https://docs.triton.one).
